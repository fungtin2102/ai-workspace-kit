# Module Memory Bank Protocol

Before starting work:
1. Prefer the six root core files under `../memory-bank/`.
2. If they do not exist, ask the user for the root project path or ask them to add the root project to the workspace.
3. Read the root module status file: `<ROOT_PROJECT_PATH>/memory-bank/module-<MODULE_NAME>-status.md`.

After work:
- Update the root module status file.
- If there is cross-module impact, write it to root `dev-doc/` and mention it in the handoff.
- Do not create a second `memory-bank/` inside the module.
