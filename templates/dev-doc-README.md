# Dev Doc

`dev-doc/` is the root workspace for cross-module contracts, draft designs, integration notes, and troubleshooting records.

Good uses:
- Frontend/backend API contracts.
- Service events, fields, and state-machine agreements.
- Database migration strategies.
- Third-party integration notes.
- Integration checklists.
- Draft designs that are not yet stable enough for formal documentation.

Avoid storing:
- Large build artifacts.
- Deprecated source snapshots.
- Module-internal implementation logs.
