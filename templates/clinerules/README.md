# Cline / Kiro Rules

This directory is the collaboration rule entry point for Cline, Kiro, and other AI tools that can read project rule directories.

Read first:
- `memory-bank-protocol.md`
- `init-memory-bank.md`
- Root `AGENTS.md`
- Module `AGENTS.md`

## Common Rules

- Root `memory-bank/` is the single source of truth for project state.
- Root `dev-doc/` stores cross-module contracts and draft designs.
- Module sessions edit only their own module by default.
- After substantive work, update the relevant module status file in root Memory Bank.
